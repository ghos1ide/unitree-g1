ELN 基本控制 HTTP 接口协议

版本：V1.5

通信方式HTTP/HTTPS + JSON，全部业务接口使用 POST
调用方向ELN 下发任务；机器人回调任务状态
字符编码UTF-8

1. 通用约定

ELN 调用机器人服务地址：https://{robot-host}/api/v1。机器人回调 ELN 地址由 ELN 在任务请求中提供。

请求头说明
Content-Typeapplication/json

时间统一采用 ISO 8601 格式，例如：2026-09-20T17:00:00+08:00。

2. 机器人初始化接口

POST /api/v1/robot/initialize

ELN 在执行控制任务前调用该接口，使机器人完成基础自检、执行机构回零和控制系统准备。

{
  "taskId": "INIT-20260920-0001",
  "callbackUrl": "https://eln-host/eln/api/v1/robot-callbacks/task-status"
}

接收响应：

{
  "code": 0,
  "message": "accepted",
  "taskId": "INIT-20260920-0001",
  "status": "ACCEPTED"
}

该响应只表示初始化任务已接收。初始化状态通过统一回调接口上报，taskType 固定为 ROBOT_INITIALIZE；开始时 progress=0，完成时 progress=1。

3. 控制任务下发接口

POST /api/v1/tasks

3.1 通用请求结构

{
  "taskId": "TASK-20260920-0001",
  "taskType": "NWS_CYCLE",
  "callbackUrl": "https://eln-host/eln/api/v1/robot-callbacks/task-status",
  "parameters": {
    "count": 20
  }
}
字段类型必填说明
taskIdstring是ELN 生成的唯一任务号；相同 taskId 不得重复执行
taskTypestring是任务类型：NWS_CYCLE、NLG_WOW_OPERATION 或 GEAR_OPERATION
callbackUrlstring是机器人上报状态的 ELN 地址
parametersobject是任务参数，定义见第 4 章

3.2 接收响应

{
  "code": 0,
  "message": "accepted",
  "taskId": "TASK-20260920-0001",
  "status": "ACCEPTED"
}

该响应只表示任务已接收，不表示动作已经完成。

4. 控制任务参数

4.1 前轮转弯连续动作

taskType = NWS_CYCLE
{
  "taskId": "TASK-20260920-0001",
  "taskType": "NWS_CYCLE",
  "callbackUrl": "https://eln-host/eln/api/v1/robot-callbacks/task-status",
  "parameters": {
    "count": 20
  }
}
字段类型说明
countinteger需要完成的前轮转弯操作次数，必须为正整数
计数规则：前轮完成“左旋一次 + 右旋一次”后，视为完成 1 次操作，progress 加 1。单独完成左旋或右旋均不计为一次完整操作。

机器人按照本地预设的全行程动作曲线连续执行。若 count=20，则应完成 20 组“左旋一次 + 右旋一次”，共包含 20 次左旋和 20 次右旋。

4.2 前起落架承重与 WOW 信号模拟

taskType = NLG_WOW_OPERATION

模拟空中状态：

{
  "taskId": "TASK-20260920-0002",
  "taskType": "NLG_WOW_OPERATION",
  "callbackUrl": "https://eln-host/eln/api/v1/robot-callbacks/task-status",
  "parameters": {
    "wowSignal": "AIR"
  }
}

模拟地面状态：

{
  "taskId": "TASK-20260920-0003",
  "taskType": "NLG_WOW_OPERATION",
  "callbackUrl": "https://eln-host/eln/api/v1/robot-callbacks/task-status",
  "parameters": {
    "wowSignal": "GROUND"
  }
}
字段类型说明
wowSignalstring目标 WOW 状态：AIR 表示空中；GROUND 表示地面

WOW 信号达到目标状态后，任务才可上报成功，完成时 progress=1。

4.3 起落架连续收放

taskType = GEAR_OPERATION

标准完整循环示例：

{
  "taskId": "TASK-20260920-0004",
  "taskType": "GEAR_OPERATION",
  "callbackUrl": "https://eln-host/eln/api/v1/robot-callbacks/task-status",
  "parameters": {
    "count": 5,
    "preAction": "NONE",
    "cycleMode": "FULL_CYCLE"
  }
}

最后一次仅收起示例：

{
  "taskId": "TASK-20260920-0005",
  "taskType": "GEAR_OPERATION",
  "callbackUrl": "https://eln-host/eln/api/v1/robot-callbacks/task-status",
  "parameters": {
    "count": 5,
    "preAction": "NONE",
    "cycleMode": "FINAL_RETRACT_ONLY"
  }
}

正式计数前先放下示例：

{
  "taskId": "TASK-20260920-0006",
  "taskType": "GEAR_OPERATION",
  "callbackUrl": "https://eln-host/eln/api/v1/robot-callbacks/task-status",
  "parameters": {
    "count": 5,
    "preAction": "EXTEND_DOWNLOCK",
    "cycleMode": "FULL_CYCLE"
  }
}
字段类型说明
countinteger需要完成的起落架操作次数，必须为正整数
preActionstringNONE：无预动作；EXTEND_DOWNLOCK：正式计数前先放下并确认下位锁上锁，预动作不计数
cycleModestringFULL_CYCLE：每次执行完整“收起→放下”，任务完成时起落架处于下位锁上锁状态；FINAL_RETRACT_ONLY：前 count-1 次执行完整循环，最后一次仅收起，任务完成时起落架处于上位锁上锁状态

FULL_CYCLE 模式下，每完成一次“收起→放下”且确认下位锁上锁，progress 加 1。FINAL_RETRACT_ONLY 模式下，前 count-1 次按完整循环计数；最后一次在收起并确认上位锁上锁后计数，且不得继续放下。

5. 状态回调接口

机器人在任务状态变化或已完成次数变化时调用 ELN：

POST {callbackUrl}
{
  "taskId": "TASK-20260920-0001",
  "taskType": "NWS_CYCLE",
  "status": "RUNNING",
  "progress": 8,
  "message": "已完成8/20次前轮转弯操作",
  "timestamp": "2026-09-20T17:00:00+08:00",
  "errorCode": null
}

5.1 回调触发时机

  • 任务被机器人接收后，上报 ACCEPTED。
  • 机器人开始执行时，上报 RUNNING，progress=0。
  • NWS_CYCLE 每完成一组“左旋一次 + 右旋一次”，progress 加 1。
  • NLG_WOW_OPERATION 在 WOW 信号达到目标状态后，progress 更新为 1。
  • GEAR_OPERATION 按对应循环模式的完整计数条件更新 progress。
  • 正常完成后上报 SUCCEEDED；失败上报 FAILED；完成受控取消后上报 CANCELLED。

推荐状态流转：ACCEPTED → RUNNING → SUCCEEDED / FAILED / CANCELLED。最终状态不得回退。

5.2 回调字段说明

字段类型必填说明
taskIdstring是ELN 下发的任务唯一编号，机器人原样返回
taskTypestring是任务类型
statusstring是ACCEPTED、RUNNING、SUCCEEDED、FAILED 或 CANCELLED
progressinteger是已完成次数，不是百分比
messagestring是可读状态说明，建议包含当前动作、已完成次数和总次数
timestampstring是状态产生时间，ISO 8601 格式并包含时区
errorCodestring/null是非失败状态填写 null；FAILED 时填写业务错误码

5.3 progress 填写规则

  • NWS_CYCLE：每完成一组“左旋一次 + 右旋一次”加 1；只完成其中一个方向时不增加。
  • NLG_WOW_OPERATION：开始时为 0；WOW 信号达到目标状态后为 1。
  • GEAR_OPERATION：按照 cycleMode 定义的完成条件计数；preAction 不计数。
  • FAILED 或 CANCELLED 时，progress 保留停止前已经完整完成的次数；未完成的当前动作不得计数。

5.4 回调应答

{
  "code": 0,
  "message": "received"
}

code=0 表示 ELN 已接收回调。机器人未收到成功应答时可重复发送；ELN 应依据 taskId + status + progress + timestamp 去重。

6. 查询与取消

POST /api/v1/tasks/{taskId}/query

查询任务当前状态和已完成次数。

POST /api/v1/tasks/{taskId}/cancel
{ "reason": "ELN operator cancelled" }

取消是受控停止请求。机器人无法立即安全停止时，应完成安全停机流程，并通过回调返回最终状态。

7. 统一错误码

code说明
0成功或已接收
1001参数错误
1002未授权
1003任务号重复
2001机器人忙
2002安全条件不满足
2003初始化未完成
2004执行机构故障

8. 安全与执行要求

  • 起落架收起或放下动作只有在对应上位锁或下位锁确认后，才可判定该阶段完成。
  • FINAL_RETRACT_ONLY 的最后一次确认上位锁后必须停止，不得自动继续放下。
  • EXTEND_DOWNLOCK 预动作必须确认下位锁上锁后，才可开始正式计数。
  • NLG_WOW_OPERATION 必须校验 WOW 信号是否达到目标状态；未达到目标不得上报成功。
  • 安全联锁、硬件急停或人员进入危险区域时，机器人应停止后续动作，并按实际已完成次数回调 FAILED 或 CANCELLED。
